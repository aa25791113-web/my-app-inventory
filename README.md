# MY APP — نظام إدارة المخزون والمبيعات

تطبيق Flutter عربي بالكامل باتجاه RTL، مصمم للعمل محلياً دون الحاجة إلى حساب أو خادم أو اتصال إنترنت أثناء الاستخدام اليومي. قاعدة البيانات SQLite محفوظة على الجهاز.

## الوظائف الموجودة
- لوحة رئيسية تعرض أعداد المنتجات والكميات وقيمة المخزون وتنبيهات النواقص وإجماليات البيع والشراء.
- إدارة المنتجات: إضافة وتعديل وحذف، التصنيف، الكمية، حد إعادة الطلب، سعر الشراء وسعر البيع، والبحث.
- تسجيل المبيعات والمشتريات مع تحديث الكمية تلقائياً ومنع البيع فوق الرصيد المتاح.
- حفظ سجل كل حركة مع المنتج والكمية والسعر والتوقيت والملاحظات.
- إدارة ملفات الموردين والعملاء وبيانات التواصل والأرصدة الافتتاحية، وربط المورد بعملية الشراء والعميل بعملية البيع.
- إدارة قائمة المخازن ومواقعها.
- تسجيل المصروفات التشغيلية وتصنيفاتها وملاحظاتها.
- الجرد والتسوية اليدوية للكمية مع تسجيل فرق الجرد وسببه.
- تقارير إجمالي المبيعات والمشتريات والمصروفات والربح التقديري وصافي الربح بعد المصروفات.
- تنبيهات انخفاض المخزون.
- الوضع الفاتح والداكن، ألوان واجهة متعددة، خلفية مخصصة، واسم وشعار مخصصان داخل الواجهة.
- تقارير قابلة للطباعة أو الحفظ PDF: جرد المنتجات، سجل المبيعات والمشتريات، التقرير المالي، العملاء والموردون، المخازن والمصروفات.
- أيقونة افتراضية مخصصة للتطبيق على Android وWindows، واسم عرض MY APP في نسخة Android المثبتة.
- تصدير واستيراد نسخة احتياطية JSON تشمل المنتجات والحركات والموردين والعملاء والمخازن والمصروفات وتسويات الجرد.
- قاعدة بيانات محلية؛ لا يوجد اشتراك أو خادم مطلوب.

## البناء
- الإصدار الحالي: `1.2.0+3`.
- Android: GitHub Actions → Build Android APK → artifact: `my-app-android-apk`.
- Windows: GitHub Actions → Build Windows App → artifact: `my-app-windows` ويحتوي ملف التثبيت `MY-APP-Setup.exe` والنسخة المحمولة ZIP.

## ملاحظات مهمة
- التطبيق يعمل دون إنترنت في وظائفه المحلية.
- نقل البيانات بين الهاتف والكمبيوتر يتم عبر تصدير ملف النسخة الاحتياطية ثم استيراده على الجهاز الآخر.
- نسخة Windows تُبنى كملف تثبيت EXE بالإضافة إلى النسخة المحمولة ZIP.
- تغيير الاسم والشعار والخلفية من الإعدادات يغيّر الواجهة داخل التطبيق؛ أيقونة المشغّل واسم التطبيق الخارجيان يحددهما ملف البناء، ويتطلب تغييرهما إصدار APK/تثبيت جديد. الشعار الذي تختاره من داخل الإعدادات لا يبدّل أيقونة Android خارج التطبيق تلقائياً.
- يجب اختبار التطبيق عملياً على الأجهزة المستهدفة قبل الاعتماد النهائي.
- أرصدة الموردين والعملاء الافتتاحية محفوظة كبيانات تعريفية؛ الربط المحاسبي الآلي الكامل لكل فاتورة/دفعة ما زال مجال تطوير لاحق.
