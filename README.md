# MY APP — إدارة المخزون

تطبيق عربي RTL لإدارة المنتجات والمخزون والمبيعات والمشتريات، باستخدام Flutter وSQLite محلية.

## الوظائف الحالية
- إضافة المنتجات وتعديلها وحذفها، مع التصنيف والكمية وحد التنبيه وأسعار الشراء والبيع.
- البحث عن المنتجات بالاسم أو التصنيف.
- تسجيل عمليات البيع والشراء مع تحديث المخزون تلقائياً.
- منع بيع كمية أكبر من المخزون المتاح.
- سجل تفصيلي للحركات والملاحظات والتوقيت.
- لوحة رئيسية بإجماليات المنتجات والكميات والتنبيهات وقيمة المخزون.
- تقارير إجمالي المبيعات والمشتريات وصافي الحركة وقائمة الجرد.
- تنبيهات انخفاض المخزون.
- الوضع الفاتح والداكن.
- إنشاء نسخة احتياطية محلية بصيغة JSON واستعادة آخر نسخة.
- حفظ البيانات محلياً باستخدام SQLite؛ لا يلزم اتصال بالإنترنت ولا حساب أو خادم.

## إنشاء Android APK
افتح تبويب **Actions** ثم **Build Android APK**. بعد نجاح التشغيل نزّل artifact باسم `my-app-android-apk`.

## إنشاء تطبيق Windows
افتح تبويب **Actions** ثم **Build Windows App**. بعد نجاح التشغيل نزّل artifact باسم `my-app-windows`.

## ملاحظات
- APK ونسخة Windows يجب اختبارهُما على أجهزتهما الفعلية قبل الاعتماد النهائي.
- النسخة الاحتياطية تُحفظ في مجلد مستندات التطبيق على الجهاز.
- هذا الإصدار محلي بالكامل؛ نقل البيانات بين الأجهزة يحتاج نقل ملف النسخة الاحتياطية يدوياً.
