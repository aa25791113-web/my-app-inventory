# MY APP — نظام إدارة المخزون الذكي

تطبيق Flutter عربي باتجاه RTL، بقاعدة بيانات SQLite محلية، ويعمل في وظائفه الأساسية دون حساب أو خادم أو اتصال إنترنت.

## الإصدار
- الإصدار: `3.7.0+38`.
- Android: APK منفصل حسب معمارية الجهاز لتقليل الحجم.
- Windows: ملف تثبيت EXE ونسخة محمولة ZIP.

## الوظائف الحالية في هذا الإصدار
- شاشة بحث أسعار سريعة هي الشاشة الافتراضية عند فتح التطبيق.
- بحث محلي فوري بالاسم والكود ورقم القطعة والماركة والشركة المصنعة والأسماء البديلة والموقع والمواصفات، مع دعم كلمات البحث المتعددة.
- توليد كود فريد تلقائيًا لكل منتج بصيغة حرف إنجليزي و5 أرقام، مع السماح بكود يدوي والتحقق من عدم التكرار.
- إضافة صورة رئيسية للمنتج من المعرض أو الكاميرا، وحفظها محليًا.
- بحث بالصورة محليًا بمقارنة perceptual hash للصور المحفوظة؛ النتائج تقريبية وليست ذكاءً اصطناعيًا دلاليًا.
- إنشاء QR للمنتج وعرضه، ومسح QR/الباركود بالكاميرا على Android وiOS.
- إدارة بيانات قطع الغيار: رقم القطعة الأصلي والبديل، الماركة، الشركة المصنعة، الوحدة، بلد المنشأ، أسماء بديلة، المواصفات، الموديلات المتوافقة، المقاسات، الوزن، موقع التخزين، وسعر الجملة.
- إدارة التصنيفات.
- ربط المنتج بمورد محفوظ محليًا.
- المفضلة، الأرشيف والاستعادة، وسجل عمليات البحث.
- سجل تغييرات أسعار الشراء والبيع مع سبب وتوقيت التعديل، وتعديل جماعي لسعر البيع مع حفظ السعر السابق.
- أدوات فحص الأصناف بدون صور أو بدون أسعار، واكتشاف الأسماء المكررة.
- قائمة مهام وسجل نشاط محلي مع إمكانية حذف المهام والسجلات والبحث المحفوظ.
- حذف المصروفات والتصنيفات والمخازن والملاحظات والمفضلة والحركات مع عكس أثر حذف الحركة على المخزون.
- مساعد أوامر محلي دون إنترنت للبحث عن المنتجات بالاسم أو الكود أو الأسماء البديلة، وإضافة منتج بعد مراجعة البيانات وتأكيد المستخدم.
- المخزون والجرد والتسويات وتسجيل الحركات.
- الموردون والعملاء والمخازن والمصروفات والتقارير والطباعة.
- تصدير CSV كامل لبيانات المنتجات واستيراد أصناف CSV دون حذف الأصناف الموجودة.
- نسخ احتياطي JSON يشمل البيانات وسجلات الأسعار والتصنيفات والمفضلة والمهام وصور المنتجات المرفقة بصيغة Base64، مع استعادة داخل معاملة قاعدة بيانات.
- تخصيص اسم الواجهة والشعار والخلفية والألوان والوضع الليلي ورمز العملة.

## بناء Android وWindows
يتم البناء عبر GitHub Actions:
- Android: workflow باسم **Build Android APK**؛ ينتج APKs منفصلة لمعمارية ARM64 وARM وx86_64 لتقليل حجم التنزيل.
- Windows: workflow باسم **Build Windows App**؛ ينتج ملف تثبيت `MY-APP-Setup.exe` ونسخة محمولة ZIP.

## حدود يجب معرفتها قبل الاعتماد التجاري
- مطابقة الصور محلية وتقريبية، وليست نموذج ذكاء اصطناعي متقدمًا أو ضمانًا للتوافق.
- شاشة توزيع المخزون الجديدة تعرض رصيد كل منتج في المخزن المختار وتسمح بتحويل الكميات بين المخازن مع التحقق من الرصيد وحفظ سجل التحويل.
- مسح الكاميرا متاح على Android/iOS مع إيقاف القراءة بعد أول كود صالح؛ Windows يعتمد على البحث اليدوي والكود.
- مساعد البرنامج محلي قائم على أوامر محددة، وليس نموذج محادثة عامًّا؛ لا ينفّذ أوامر غير مدعومة ولا يغيّر البيانات دون تأكيد.
- الاستيراد الجماعي الحالي يدعم CSV؛ ملفات XLSX الأصلية تحتاج تحويلًا إلى CSV أولًا.
- أرصدة مستقلة لكل منتج داخل كل مخزن، مع تحويلات بين المخازن وسجل للتحويلات. العمليات اليومية الحالية تسجل تلقائياً على المخزن الرئيسي؛ اختيار مخزن مختلف داخل شاشة البيع والشراء لم يُربط بعد.
- دفتر حسابات متكامل للموردين والعملاء، وتسجيل دفعات وتسويات أرصدة، ليس جزءًا مكتملًا بعد.
- لا توجد حتى الآن اختبارات أجهزة فعلية آلية أو اعتماد على 100 منتج بعد فصل الإنترنت؛ يجب إجراء اختبار قبول على الهاتف والكمبيوتر قبل الاستخدام التجاري النهائي.
- نقل البيانات بين الأجهزة يتم بتصدير النسخة الاحتياطية ثم استيرادها على الجهاز الآخر.
- تغيير اسم وأيقونة المشغّل الخارجيين يتطلب بناء حزمة جديدة؛ تغيير الشعار من الإعدادات يغيّر الشعار داخل الواجهة فقط.
