# MY APP — إدارة المخزون

تطبيق عربي باتجاه RTL لإدارة المخزون، مبني باستخدام Flutter وSQLite، ومخطط لتشغيله محلياً على Android وWindows دون اتصال بالإنترنت.

## الوظائف الموجودة في النسخة التأسيسية
- إضافة المنتجات وتعديلها وحذفها.
- تسجيل التصنيف والكمية وحد التنبيه وسعر الشراء والبيع.
- البحث بالاسم أو التصنيف.
- ملخص عدد المنتجات وإجمالي الكمية ونواقص المخزون.
- تنبيه مرئي عندما تصل الكمية إلى حد التنبيه.
- مظهر فاتح وداكن.
- قاعدة بيانات SQLite محلية.

## بناء Android
من تبويب **Actions** اختر **Build Android APK** وشغّل workflow يدوياً. بعد نجاحه نزّل artifact باسم `my-app-android-apk`.

## بناء Windows
من تبويب **Actions** اختر **Build Windows App** وشغّل workflow يدوياً. بعد نجاحه نزّل artifact باسم `my-app-windows`.

## ملاحظات مهمة
- هذه نسخة تأسيسية وليست كل نظام المخازن النهائي بعد.
- لا يوجد خادم أو حساب سحابي مطلوب لتشغيل الوظائف الأساسية.
- يجب انتظار نجاح البناء وفحص سجلات GitHub Actions قبل اعتبار ملفات التثبيت جاهزة.
- لم يتم بعد اختبار APK على هاتف Android فعلي أو نسخة Windows على جهاز فعلي.
